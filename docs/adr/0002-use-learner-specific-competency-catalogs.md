# Use learner-specific competency catalogs

Each Learner will have a Mentor-approved Competency Catalog rather than sharing one installation-wide catalog. Reusable templates provide consistent starting subtrees, but approval copies selected nodes into the Learner's catalog so it can follow that person's stacks, work, and development goals without forcing every Learner into the same taxonomy; referenced nodes remain traceable when later renamed, moved, archived, or merged.
